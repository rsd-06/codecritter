Download CodeCritter

Free and open source. Pick your system, click once, and your critter is on the desktop.

CodeCritter is a desktop app. Open this page on your computer to install it, or download a file below and move it over.

Windows

Your system Windows 10 and 11, 64-bit
Installer (.exe) recommended CodeCritter_x64-setup.exe MSI package (.msi) CodeCritter_x64_en-US.msi

First run. Builds are unsigned for now. If SmartScreen says "Windows protected your PC", choose More info, then Run anyway. The installer is per user and needs no admin rights.

macOS

Your system Apple silicon and Intel Beta: untested, feedback welcome
Disk image (.dmg) recommended CodeCritter_universal.dmg App archive (.app.tar.gz) CodeCritter_universal.app.tar.gz

First run. The app is not notarized yet, so macOS blocks a double-click. Right-click (or Control-click) CodeCritter in Applications, choose Open, then Open again. It asks only once.

Linux

Your system x86-64 Beta: untested, feedback welcome
AppImage runs anywhere CodeCritter_amd64.AppImage Debian / Ubuntu (.deb) CodeCritter_amd64.deb

First run. Make the AppImage executable, then run it: chmod +x CodeCritter_*.AppImage. For the .deb: sudo apt install ./CodeCritter_*.deb.

Prefer GitHub? All files, release notes and checksums are on the releases page. Could not reach GitHub to look up the newest file names, so the buttons open the releases page instead.

Everything runs locally: no account, no telemetry. Curious how it works with your AI agent? See the agent demo.
