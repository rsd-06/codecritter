Everything it does

Eighteen features, all running locally. Most of them you only notice when they happen.

It reacts to you

  • Typing Paws knead along with your keys. Key counts only, never what you type.
  • Overheat Hammer the keyboard for a few seconds and it turns red and steams.
  • Scrolling Scroll and it unrolls a paper roll (a scroll for Yoda).
  • Cursor eyes Pupils and head follow your cursor across every monitor.
  • Mouse hunt Whip the cursor past it and it crouches, wiggles and pounces.
  • Petting Rub the cursor over its head for hearts and a purr.
  • Drag and shake Grab it like mochi. Shake it and it gets dizzy.

It looks after you

  • Idle and sleep It gets bored when you leave and falls asleep, then wakes the moment you return.
  • Stretch and water Reminders on your own schedule, with do-not-disturb hours.
  • Pomodoro Focus, break and long-break loops with a pixel timer beside it.
  • Scheduled messages A note at a set time: once, daily or on weekdays.
  • Pinned note A sticky note that stays above its head.
  • Your name Bubbles use your name. Yoda keeps his syntax.

It stays out of your way

  • Peek mode Hides at a screen edge while a fullscreen app or video is up. Only reminders break through.
  • Tray and shortcuts Switch character, run Pomodoro, mute or hide from the tray. Global hotkeys for peek, hide and settings.
  • Settings sync Export and import settings, or point it at a sync folder to share them across machines.
  • Make it yours Edit colours with a live preview, scale 1 to 4x, opacity, sound and volume.
  • Click-through Clicks pass through everything except the critter itself.
  • Autostart Optional. Quiet by design.

How it works with your agent

  1. Install the hook. Open Settings, then Agents, and click Install. CodeCritter edits your agent's config for you, keeps a backup, and can uninstall just as cleanly.
  2. Work as usual. The agent's hook sends a tiny status event to an endpoint on your own machine (127.0.0.1, with a random token).
  3. Watch the critter. It thinks along, hops when the agent is done and sounds the alarm on errors or questions.

One-click install: Claude Code, Codex CLI, Cursor, Gemini CLI, Antigravity, Kiro, GitHub Copilot CLI and OpenCode. Devin and anything else: one curl call. Agent setup guide

Private and tiny

  • Counts, not content. Keystrokes become a rate. Key identities never leave the input hook and are never stored.
  • No telemetry, no network. No analytics, no update ping. The agent endpoint only listens on your own machine and rejects browser requests.
  • Quiet when idle. It redraws about once a second at rest, and only while animating otherwise.

Install

Windows

Download CodeCritter_*_x64-setup.exe. It installs per user, no admin needed, and fetches the WebView2 runtime only if your PC lacks it.

Download for Windows

Builds are unsigned for now. If SmartScreen says "Windows protected your PC", choose More info, then Run anyway.

macOS and Linux

Build from source for now (Node 22+, Rust, and the Tauri prerequisites). Prebuilt packages will come once they are tested on real machines. 

git clone https://github.com/rsd-06/codecritter.git
cd codecritter
npm ci
npm run dist
